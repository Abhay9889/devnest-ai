How DevNest AI works.

A small architecture designed to keep the public app simple and API credentials private.

Architecture

Browser → Vercel frontend → /api/generate serverless function → Anthropic Messages API → response.

01Public static UI
02Server-side API boundary
03Environment secret
04Claude response

Enable Claude

In Vercel, add an environment variable named ANTHROPIC_API_KEY. Optionally set ANTHROPIC_MODEL. Redeploy after changing environment variables.

The key is never placed in HTML, CSS, JavaScript, GitHub, or the browser.

Local development

Install Vercel CLI, run vercel dev, and configure the environment variable locally. The browser calls only /api/generate.

Current status

The public playground works in demo mode without an API key. Real Claude responses require legitimate Anthropic API access.
